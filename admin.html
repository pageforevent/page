관리자 초기 설정

간단한 비밀번호만으로 어디서든 접속하여 수정할 수 있도록 비밀번호와 GitHub 토큰을 1회 등록합니다.

🔑 GitHub Token(PAT) 발급 방법 (1분 소요)
  1. GitHub 토큰 생성 페이지 열기
  2. Note에 'page-admin' 입력, 권한에서 repo 체크박스 선택
  3. 페이지 하단 Generate token 클릭 후 생성된 ghp_... 토큰 복사
이후 관리자 페이지에 접속할 때 이 비밀번호만 입력하면 됩니다.
토큰은 입력하신 비밀번호로 AES-GCM 암호화되어 안전하게 보관됩니다.
